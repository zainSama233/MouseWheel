# 鼠标快捷强化 · 产品设计

后续范围见 [迭代方向](next-version.md)。

## 产品方向

通过鼠标附近的工具轮盘，快速打开常用应用、网页和桌面工具。以轻量常驻、低资源占用、低延迟和便携使用为目标。

目标平台为 Windows 10、Windows 11 和 macOS。当前可运行平台及尚未完成的验证见 [验证记录](validation.md)。

## 核心体验

1. 按住鼠标中键，在鼠标位置呼出轮盘。
2. 移动到动作槽位，松开中键执行；主中心默认取消，启用中心动作后在死区内释放执行；槽位间空隙、空槽位和轮盘外释放均取消，Esc 也可取消。
3. 悬停分组槽位展开子轮盘，继续移动选择动作；移回中心返回主轮盘。刚展开便松开不会执行光标下的新动作。
4. 呼出采用短暂淡入与轻微缩放，动画期间即可选择，松开无需等待动画结束。

轮盘不抢走原应用的输入焦点。成功触发时配对消费中键输入；暂停后恢复原功能，滚轮保持正常。屏幕边缘调整布局，不移动系统鼠标。

## 主要功能

| 模块 | 范围 |
| --- | --- |
| 轮盘 | 主轮盘及一级子轮盘各支持 4／8／12 槽位，默认 8；形态为 Original 紧凑扇区、Circle 悬浮圆形、Capsule 圆角胶囊、HexagonHive 蜂巢六边形；显示与命中共用布局。 |
| 动作 | 分类与参数见下方动作体系；每个槽位独立选择动作、图标和名称显示。 |
| 设置 | 左侧方案与聚焦编辑，右侧固定画布及紧凑列表；缩放、平移、复位、点击与跨级换位。支持简体中文、繁体中文、English、日本語即时切换，保留输入草稿和画布视角。 |
| 图标 | 自动获取、内置矢量、程序图标与共享本地图标库；SVG 保留矢量原文件，PNG／ICO／JPG 按显示尺寸读取；支持搜索、重命名和删除，图标独立于动作。 |
| 中心 | 主中心可独立配置动作、图标和排版，执行默认关闭；死区可调整。子中心始终返回，不接受动作换位。 |
| 外观 | 跟随系统、明亮、护眼、深色、莫兰迪柔灰及海洋蓝；可选毛玻璃材质。方案与槽位提供折叠的颜色和排版覆盖；有效改动即时预览。 |
| 触发 | 默认单独中键，也可配置修饰键与鼠标键组合；可按应用暂停，并可开启全屏暂停，暂停时恢复原按键功能。 |
| 常驻 | 托盘提供设置、暂停／恢复、重新连接输入与退出。设置打开时暂停轮盘。 |
| 配置 | 全局方案与应用专属方案，可新建、复制、重命名、删除和绑定完整 EXE 路径；未匹配时回退全局。图标库和颜色预设共用。 |

## 配置交互

- 在主轮盘槽位的动作分类中选择“子轮盘”，通过“编辑子轮盘”进入；子轮盘不再提供分组动作。
- 减少槽位数量前，须先移动或清空超出范围的已配置槽位；不会静默删除动作。分组换位包含内部动作，清空非空分组需要明确确认。
- 切换轮盘或数量前，当前页未完成的槽位须先补全或清空；草稿保留，仍可保存其他设置或关闭窗口。


- 轮盘预览与运行时共用图文布局和命中规则。拖拽交换整个槽位，包含排版；拖动时悬停分组进入子层，悬停子中心返回。普通动作可与主中心交换，分组只能放在主轮盘外圈。空隙和轮盘外不是交换目标，保存失败保留原槽位。
- 应用选择器按需加载，支持名称／路径搜索与手动刷新；应用来源为开始菜单、桌面快捷方式和系统注册的桌面程序。运行窗口列表排除本程序。未列出的程序可浏览 EXE 或通过原有文件选择入口添加。
- 自动图标模式下，程序读取 EXE 图标，快捷方式先解析目标；选择应用保留手动名称与图标，勾选“使用程序图标”可显式替换。新目标不继承旧目标的额外参数和工作目录，快捷方式自带的启动信息保留。
- 暂停应用按完整 EXE 路径匹配；可以从应用列表、运行窗口或文件选择器添加和移除。全屏指窗口覆盖所在显示器，普通最大化窗口通常不属于全屏。两个选项默认关闭／为空。

- 网站在自动图标模式下，编辑网址后异步读取页面声明的图标，未声明时尝试站点 favicon；结果缩小为 PNG 随配置保存。失败时显示原因并可重试，手动图标不被网络结果覆盖。
- 未填完整的槽位保留最近一次有效配置，设置页标明待填写项；关闭窗口不会要求点击额外的保存按钮。

## 方案与外观工作区

- 配置方案按前台程序完整路径匹配；新建或复制方案后，可用应用选择器或运行窗口绑定。复制仅复用轮盘内容，应用绑定需重新指定；全局方案不能删除。
- 暂停、排除名单和全屏放行优先于专属方案。一次按住操作使用呼出时的方案，期间修改设置不会改变该次动作。
- 导入图标复制到配置目录，相同内容去重；源文件可移走。重命名保留引用，删除被引用图标时确认恢复自动图标。旧自定义图片在启动迁移，自动程序／网站图标保持原有获取方式。
- 颜色与排版继承顺序为主题、方案覆盖、槽位覆盖。折叠面板支持底色、光晕、边框、文字、字体、字号、图标大小、上下／左右排版及偏移；恢复继承会清除覆盖。
- 颜色可输入十六进制、使用色盘或屏幕吸色；命名颜色预设可复用、重命名与删除。预设删除不改变已经应用的颜色。
- 毛玻璃在呼出时对桌面采样并模糊，在本次显示期间复用；不会持续采样背景。设置画布用示例背景预览材质。
- 边缘策略提供平移与缩小，X／Y 安全边距以逻辑像素设置；边界包含图文偏移、边框与光晕，不移动系统光标。真实平台与多屏验收状态见 [验证记录](validation.md)。

## 动作体系

| 分类 | 范围 |
| --- | --- |
| 快捷热键 | 录制、搜索主按键、修饰键拼装；包含 Pause／Break。独占录入期间消费可拦截的按键，完成或取消后恢复。系统保留的安全组合不属于可录入范围。 |
| 启动程序 | EXE、快捷方式及关联文件；支持搜索桌面应用、选择运行窗口和浏览文件。保留快捷方式自身参数，可设置原生参数、工作目录及普通权限启动。 |
| 打开网址 | HTTP／HTTPS；系统默认、Chrome、Edge、Firefox、自定义浏览器。 |
| 打开文件夹 | 本地路径、桌面、下载、文档、图片、用户目录、此电脑、回收站。 |
| 运行命令 | CMD、PowerShell、WSL；支持工作目录、显示／隐藏终端。使用已安装的系统环境。 |
| 屏幕 OCR | 共享框选；本地 Windows OCR、兼容 Chat Completions 的视觉模型、自定义 HTTP。结果可编辑和复制；关闭结果窗口取消远程请求并忽略迟到结果。 |
| 窗口管理 | 切换、左右平铺、下一显示器、置顶、透明度、最大化／还原、最小化；作用于轮盘呼出时的窗口。 |
| 系统控制 | 锁屏、音量、媒体、任务视图、虚拟桌面、显示桌面。 |

本地 OCR 使用已安装的 Windows OCR 语言。远程识别只在用户执行对应动作时发送所选区域；接口地址、凭据及模型由用户配置。HTTP 接口约定见 [接口说明](ocr-http.md)。OCR 不在空闲时加载识别任务。

## 内置工具

| 工具 | 范围 |
| --- | --- |
| 截图贴图 | 冻结屏幕后在单个显示器内框选，生成置顶贴图；支持多个贴图、拖动、滚轮缩放、复制、保存 PNG 和关闭。输出保留原始像素。 |
| 屏幕标注 | 在实时桌面透明层绘制，提供画笔、荧光笔、箭头、矩形、文字、橡皮、撤销／重做、清空和退出；少量预设颜色、三档粗细。 |

贴图不阻止设置或轮盘。屏幕标注绘制时暂停轮盘；切换到“操作桌面”后，保留标注、放行鼠标并恢复轮盘。再次进入复用原标注，退出时清空。两项工具独立使用。

## 质量与范围边界

- 空闲时不持续轮询或运行动画；验证快速触发、取消、输入配对、焦点及资源释放。
- 覆盖屏幕边缘、不同缩放、多屏、锁屏与睡眠恢复；实际完成情况以验证记录为准。
- Windows 以解压即用为目标，无需后台服务或驱动，程序目录需要可写。
- 保持设置精简，不提供任意形状编辑、主题编辑器、宏脚本或超过两级的轮盘。
- 长截图、录屏、历史库、云同步、按应用切换轮盘和 macOS 原生后端属于后续范围。
