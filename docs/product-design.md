# 鼠标快捷强化 · 产品设计

## 产品方向

通过鼠标附近的工具轮盘，快速打开常用应用、网页和桌面工具。以轻量常驻、低资源占用、低延迟和便携使用为目标。

目标平台为 Windows 10、Windows 11 和 macOS。当前可运行平台及尚未完成的验证见 [验证记录](validation.md)。

## 核心体验

1. 按住鼠标中键，在鼠标位置呼出轮盘。
2. 移动到目标槽位，松开中键执行；中心、槽位间空隙、空槽位和轮盘外均取消，Esc 也可取消。
3. 呼出采用短暂淡入与轻微缩放，动画期间即可选择，松开无需等待动画结束。

轮盘不抢走原应用的输入焦点。成功触发时配对消费中键输入；暂停后恢复原功能，滚轮保持正常。屏幕边缘调整布局，不移动系统鼠标。

## 主要功能

| 模块 | 范围 |
| --- | --- |
| 轮盘 | 单层 8 槽位，与中心保持间距；提供扇形、圆形、六边形预设，显示与命中使用相同形状。 |
| 动作 | 打开应用、打开网页、截图贴图、屏幕标注或快捷键。常用快捷键以图标显示；应用、网页和工具附短名称。 |
| 应用 | 文件选择器选择应用或系统快捷方式，自动读取名称与系统图标；启动失败显示提示。 |
| 网页 | 配置 HTTP／HTTPS 地址，通过系统默认浏览器打开；使用本地图标，无需呼出时联网取图。 |
| 中心图片 | 导入图片后圆形裁剪显示；缩小后的图片随配置保存，不依赖原文件位置。中心仍用于取消。 |
| 主题 | 明亮、护眼、深色三种预设；形状和中心图片即时预览。 |
| 触发 | 默认单独中键，也可配置修饰键与鼠标键组合。 |
| 常驻 | 托盘提供设置、暂停／恢复、重新连接输入与退出。设置打开时暂停轮盘。 |
| 配置 | 本地自动保存，无需账号；默认槽位以 [defaultConfig](../src/core/model.cpp) 为准，已有配置由用户调整。 |

## 内置工具

| 工具 | 范围 |
| --- | --- |
| 截图贴图 | 冻结屏幕后在单个显示器内框选，生成置顶贴图；支持多个贴图、拖动、滚轮缩放、复制、保存 PNG 和关闭。输出保留原始像素。 |
| 屏幕标注 | 在实时桌面透明层绘制，提供画笔、荧光笔、箭头、矩形、文字、橡皮、撤销／重做、清空和退出；少量预设颜色、三档粗细。 |

贴图不阻止设置或轮盘。屏幕标注绘制时暂停轮盘；切换到“操作桌面”后，保留标注、放行鼠标并恢复轮盘。再次进入复用原标注，退出时清空。两项工具独立使用。

## 质量与范围边界

- 空闲时不持续轮询或运行动画；验证快速触发、取消、输入配对、焦点及资源释放。
- 覆盖屏幕边缘、不同缩放、多屏、锁屏与睡眠恢复；实际完成情况以验证记录为准。
- Windows 以解压即用为目标，无需后台服务或驱动，程序目录需要可写。
- 保持设置精简，不提供任意形状编辑、主题编辑器、宏脚本或多层轮盘。
- 长截图、OCR、录屏、历史库、云同步、按应用切换轮盘和 macOS 原生后端属于后续范围。
