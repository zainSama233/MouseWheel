# 鼠标快捷强化 · 产品设计

## 产品方向

通过鼠标附近的工具轮盘，快速打开常用应用、网页和桌面工具。以轻量常驻、低资源占用、低延迟和便携使用为目标。

目标平台为 Windows 10、Windows 11 和 macOS。当前可运行平台及尚未完成的验证见 [验证记录](validation.md)。

## 核心体验

1. 按住鼠标中键，在鼠标位置呼出轮盘。
2. 移动到目标槽位，松开中键执行；中心、槽位间空隙、空槽位和轮盘外均取消，Esc 也可取消。
3. 呼出采用短暂淡入与轻微缩放，动画期间即可选择，松开无需等待动画结束。

轮盘不抢走原应用的输入焦点。成功触发时配对消费中键输入；暂停后恢复原功能，滚轮保持正常。屏幕边缘调整布局，不移动系统鼠标。

## 主要功能

| 模块 | 范围 |
| --- | --- |
| 轮盘 | 单层 8 槽位，与中心保持间距；提供扇形、圆形、六边形预设，显示与命中使用相同形状。 |
| 动作 | 分类与参数见下方动作体系；每个槽位独立选择动作、图标和名称显示。 |
| 设置 | 点击轮盘预览或左侧列表选择槽位，拖拽交换整槽；有效配置自动保存，未完成的配置提示错误。 |
| 图标 | 所有动作均可选择内置矢量图标、任意程序的系统图标或图片；更换动作保留图标，名称可独立显示／隐藏。 |
| 中心图片 | 导入图片后圆形裁剪显示；缩小后的图片随配置保存，不依赖原文件位置。中心仍用于取消。 |
| 主题 | 明亮、护眼、深色三种预设；形状和中心图片即时预览。 |
| 触发 | 默认单独中键，也可配置修饰键与鼠标键组合；可按应用暂停，并可开启全屏暂停，暂停时恢复原按键功能。 |
| 常驻 | 托盘提供设置、暂停／恢复、重新连接输入与退出。设置打开时暂停轮盘。 |
| 配置 | 本地自动保存，无需账号；默认槽位以 [defaultConfig](../src/core/model.cpp) 为准，已有配置由用户调整。 |

## 配置交互

- 轮盘预览与实际轮盘使用同一形状命中规则；空隙、中心和轮盘外不作为交换目标。交换包含动作、名称、图标及名称显示设置，保存失败时保留原槽位。
- 应用选择器按需加载，支持名称／路径搜索与手动刷新；应用来源为开始菜单、桌面快捷方式和系统注册的桌面程序。运行窗口列表排除本程序。未列出的程序可浏览 EXE 或通过原有文件选择入口添加。
- 选择应用保留自定义名称与图标；勾选“使用程序图标”才替换图标。新目标不继承旧目标的额外参数和工作目录，快捷方式自带的启动信息保留。
- 暂停应用按完整 EXE 路径匹配；可以从应用列表、运行窗口或文件选择器添加和移除。全屏指窗口覆盖所在显示器，普通最大化窗口通常不属于全屏。两个选项默认关闭／为空。

## 动作体系

| 分类 | 范围 |
| --- | --- |
| 快捷热键 | 录制、搜索主按键、修饰键拼装；包含 Pause／Break。独占录入期间消费可拦截的按键，完成或取消后恢复。系统保留的安全组合不属于可录入范围。 |
| 启动程序 | EXE、快捷方式及关联文件；支持搜索桌面应用、选择运行窗口和浏览文件。保留快捷方式自身参数，可设置原生参数、工作目录及普通权限启动。 |
| 打开网址 | HTTP／HTTPS；系统默认、Chrome、Edge、Firefox、自定义浏览器。 |
| 打开文件夹 | 本地路径、桌面、下载、文档、图片、用户目录、此电脑、回收站。 |
| 运行命令 | CMD、PowerShell、WSL；支持工作目录、显示／隐藏终端。使用已安装的系统环境。 |
| 屏幕 OCR | 共享框选；本地 Windows OCR、兼容 Chat Completions 的视觉模型、自定义 HTTP。结果可编辑和复制；关闭结果窗口取消远程请求并忽略迟到结果。 |
| 窗口管理 | 切换、左右平铺、下一显示器、置顶、透明度、最大化／还原、最小化；作用于轮盘呼出时的窗口。 |
| 系统控制 | 锁屏、音量、媒体、任务视图、虚拟桌面、显示桌面。 |

本地 OCR 使用已安装的 Windows OCR 语言。远程识别只在用户执行对应动作时发送所选区域；接口地址、凭据及模型由用户配置。HTTP 接口约定见 [接口说明](ocr-http.md)。OCR 不在空闲时加载识别任务。

## 内置工具

| 工具 | 范围 |
| --- | --- |
| 截图贴图 | 冻结屏幕后在单个显示器内框选，生成置顶贴图；支持多个贴图、拖动、滚轮缩放、复制、保存 PNG 和关闭。输出保留原始像素。 |
| 屏幕标注 | 在实时桌面透明层绘制，提供画笔、荧光笔、箭头、矩形、文字、橡皮、撤销／重做、清空和退出；少量预设颜色、三档粗细。 |

贴图不阻止设置或轮盘。屏幕标注绘制时暂停轮盘；切换到“操作桌面”后，保留标注、放行鼠标并恢复轮盘。再次进入复用原标注，退出时清空。两项工具独立使用。

## 质量与范围边界

- 空闲时不持续轮询或运行动画；验证快速触发、取消、输入配对、焦点及资源释放。
- 覆盖屏幕边缘、不同缩放、多屏、锁屏与睡眠恢复；实际完成情况以验证记录为准。
- Windows 以解压即用为目标，无需后台服务或驱动，程序目录需要可写。
- 保持设置精简，不提供任意形状编辑、主题编辑器、宏脚本或多层轮盘。
- 长截图、录屏、历史库、云同步、按应用切换轮盘和 macOS 原生后端属于后续范围。
