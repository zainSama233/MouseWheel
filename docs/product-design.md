# 鼠标快捷强化 · MVP 产品设计

## 产品方向

面向高频使用电脑的用户，通过鼠标附近的快捷键轮盘，减少记忆快捷键和移动到工具栏的操作成本。

目标平台为 Windows 10、Windows 11 和 macOS。先交付 Windows MVP，同时尽早在 macOS 验证全局触发、窗口焦点和快捷键发送，再完成 Mac 版本。

产品以轻量常驻、低资源占用、低延迟和便携使用为目标。首版优先保证输入可靠和日常操作流畅。

## 核心体验

1. 用户按住已配置的“键盘修饰键＋鼠标键”组合，在鼠标位置呼出轮盘。
2. 移动鼠标，指向需要执行的槽位。
3. 松开鼠标触发键，隐藏轮盘并向原应用发送配置的快捷键。
4. 在中心区域松开、选择空槽位或按 Esc，取消本次操作。

轮盘不抢走原应用的输入焦点。未触发时保留正常输入；成功触发时，相关输入由轮盘消费。执行动作时须正确处理仍按住的修饰键，避免快捷键串键或按键卡住。

## 主要功能

| 模块 | MVP 范围 |
| --- | --- |
| 触发设置 | 配置一个修饰键＋鼠标键组合；鼠标键支持右键、中键或侧键。用户可修改组合以避开已有快捷操作。 |
| 快捷轮盘 | 单层轮盘，固定 8 个槽位，允许留空；显示简短名称和明确的选中状态。 |
| 动作配置 | 每个槽位配置一个键盘快捷键和名称；快捷键按当前操作系统配置。 |
| 主题设置 | 明亮、护眼、深色三种预设，同时应用于轮盘和设置界面。护眼采用暖色配色并保持文字清晰。 |
| 常驻管理 | 托盘或菜单栏入口，支持打开设置、暂停／恢复和退出。 |
| 配置保存 | 本地自动保存，重启后恢复；无需账号和网络。 |

## 体验与质量要求

- 设置界面保持简单，减少描述性文字和装饰性边框；不提供主题编辑器或额外动画。
- 轮盘在多显示器、不同缩放比例及屏幕边缘保持可用。
- 空闲时避免持续轮询和隐藏动画；性能评估覆盖空闲常驻、轮盘呼出和设置窗口关闭后的资源释放。
- 响应延迟从触发条件满足开始测量；具体性能预算在技术验证后确定。
- 验证正常单击、双击、拖动、滚轮、快速连按、取消及动作执行，避免丢键和按键卡住。
- 验证睡眠唤醒、锁屏恢复和显示器切换后的可用性。
- Windows 以解压即用为目标，无需安装后台服务或驱动，支持配置随程序目录保存。
- macOS 提供独立应用，首次使用引导完成所需系统权限授权；分发时处理签名和公证。

## 后续迭代范围

纯鼠标双键组合、专用侧键触发、纯键盘触发、按应用切换轮盘、应用排除、配置导入导出、开机启动、多层轮盘、宏脚本及其他动作类型，均不纳入 MVP。

## 首版验收方向

用户可以完成配置、呼出、选择、执行、取消和暂停的完整流程；三种主题一致生效，配置可持久保存。目标平台上的真实环境验证应覆盖输入正确性、显示适配和资源占用。

首版的核心判断是：轮盘是否足够可靠、顺手，能够在日常工作中持续使用。
