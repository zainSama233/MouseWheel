# 后续迭代方向

当前功能以 [产品设计](product-design.md) 为准，平台与验证边界以 [验证记录](validation.md) 为准。

| 方向 | 候选范围 | 前置条件 |
| --- | --- | --- |
| 轨迹手势 | 先单段 8 方向，稳定后扩展最多 3 段；轨迹浮层与释放提示 | 明确与轮盘互斥的识别模式，避免一次移动同时触发两个动作。 |
| 手势灵敏度 | 少量预设 | 先验证物理鼠标、不同 DPI 和误触率，再考虑逐段参数。 |
| 中心执行动作 | 独立触发方式 | 保留稳定的取消／返回路径，不能让正常回中意外执行。 |
| 外观进阶 | 层级独立主题、逐槽字体与文字位置 | 先确认预设不能满足的实际需求，控制设置复杂度。 |
| 外甩取消 | 越界立即退出候选 | 当前轮盘外释放取消；改变此行为须先验证移回恢复选择的需求。 |

截图贴图和实时屏幕标注继续独立。长截图、录屏、历史库、云同步、按应用切换轮盘及 macOS 后端按具体需求另行确定范围。
