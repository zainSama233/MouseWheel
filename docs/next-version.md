# 下一版迭代候选方案

状态：讨论稿，开发范围待确认。当前能力以 [产品设计](product-design.md) 为准，平台与验证边界以 [验证记录](validation.md) 为准。

## 目标

让常用动作更容易组织、找到和执行，继续保持单手中键操作、即时保存和少量预设。建议下一版以轮盘容量和配置体验为主线。

## 建议范围

| 方向 | 下一版建议 | 范围边界 |
| --- | --- | --- |
| 轮盘容量 | 支持 4／8／12 槽位，默认 8 | 各形状共用槽位布局与命中模型；减少槽位时不得静默丢失动作。 |
| 子轮盘 | 主轮盘加一级子轮盘 | 分组槽位可展开子轮盘，不同时绑定执行动作；暂不支持无限嵌套。 |
| 配置体验 | 双栏聚焦编辑、实时画布、紧凑全览与分组导航 | 复用已有拖拽换位、应用发现和即时保存；避免同一参数出现多个写入口。 |
| 外观与边缘 | 延续圆形、扇形和六边形预设，改善屏幕边缘与不同缩放布局 | 子轮盘默认继承全局主题；暂不加入逐槽字体、图标偏移、文字位置编辑器。 |
| 动作与窗口 | 整理现有动作入口、参数提示和验证 | 不把已实现能力重复立项；跨屏及系统行为按验收记录补充真实环境验证。 |
| OCR | 改善现有识别入口与失败反馈 | 本地、AI、HTTP 继续复用现有链路；外部服务与多语言效果仍需各自验证。 |

## 子轮盘交互候选

- 全程保持中键按住；悬停分组槽位短暂停留后展开，直接松开分组槽位不执行动作。
- 子轮盘中心用于返回主轮盘；主轮盘中心用于取消。中心图片继续支持。
- 明确显示当前分组与返回入口；切换层级时不移动系统光标。
- 外部取消边界与屏幕边缘布局一起验证，不能让展开瞬间改变命中目标而误执行。
- 悬停时长、展开位置和返回路径先做交互原型验证，再确定参数。

## 暂缓与待讨论

| 项目 | 建议 | 原因与待定项 |
| --- | --- | --- |
| 中心核圆动作 | 下一版保留中心取消／返回 | 为手部回中保留稳定退出路径；若加入执行动作，须先确认独立的触发方式。 |
| 轨迹手势 | 排入后续候选，独立于本版轮盘交付 | 先确定与轮盘互斥的识别模式，避免一次移动同时触发手势和槽位。首轮可先做单段 8 方向，验证后再扩展最多 3 段。 |
| 手势调节 | 优先少量灵敏度预设 | 轨迹浮层、识别结果和释放提示有价值；逐段灵敏度先不开放。 |
| 蜂窝扇 | 需确认布局含义 | 若指六边形独立槽位则已有；若指紧密蜂窝排列，则是新的布局与导航设计。 |
| 外甩取消 | 作为明确反馈与边界体验优化 | 当前轮盘外释放已取消；是否要求越界立即关闭、是否允许移回恢复选择，需确认。 |
| 独立一二级主题与逐槽样式 | 后续候选 | 先统一继承与预设，避免配置负担超过动作本身。 |

## 实施与验收顺序

1. 统一可变槽位模型、配置存储及共享几何；验证旧配置载入、槽位数量切换与动作保留。
2. 验证两级轮盘原型，覆盖快速划过分组、悬停展开、返回、松开与取消，确保一次操作最多执行一个动作。
3. 更新配置画布与分组编辑；即时保存、拖拽换位、图标独立选择不得回退。
4. 验证边缘、多屏缩放、正常中键点击、暂停与焦点；测量触发及层级切换延迟和常驻资源变化。

配置中的轮盘结构是单一数据源，运行轮盘与设置画布共享解释方式。验收结果仅写入 [验证记录](validation.md)，不在本方案重复维护当前实现状态。
