# 第三方组件

本程序使用动态链接的 Qt。实际版本以 [toolchain.json](../toolchain.json) 为准。

- Qt 源代码：[qtbase](https://code.qt.io/cgit/qt/qtbase.git/)；按工具链版本选择同名发布标签。
- Qt 许可文本：[LGPL-3.0-only.txt](LGPL-3.0-only.txt)、[GPL-3.0-only.txt](GPL-3.0-only.txt)。
- 便携包的 Qt 软件物料清单随包放置在本目录。
- Microsoft Visual C++ Runtime 来自 MSVC 工具链的官方可再分发目录。
